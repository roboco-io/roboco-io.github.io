# 한국어 → 영어·일본어 콘텐츠 번역·동기화

한국어 `content/ko/`가 원본이다. 같은 상대 경로의 `content/en/`과 `content/ja/`를 생성·갱신한다. 한국어 URL은 루트, 영어는 `/en/`, 일본어는 `/ja/`를 사용한다. 실행 전 `hugo.yaml`의 언어 설정을 확인한다.

## 범위와 원문 확인

- 사용자나 현재 콘텐츠 작성 작업이 지정한 파일만 처리한다. 대상이 없으면 `git status`와 `git diff --name-only`로 신규·변경된 한국어 파일과 기존 번역을 확인하되, 무관한 미커밋 파일까지 번역 대상으로 확대하지 않는다. 대상이 여전히 불명확할 때만 질문한다.
- 한국어 콘텐츠를 작성·수정하는 작업에서는 사용자에게 원문을 보여주고 명시적인 확인을 받은 뒤 번역한다. 원문 수정 요청이나 셀프 리뷰 완료를 원문 확정으로 간주하지 않는다.
- 완성된 원문에 대한 직접적인 번역·동기화 요청은 번역 진행 의사로 받아들인다. 같은 확인을 다시 요구하지 않는다.
- 사용자가 한국어만 요청하거나 번역을 보류하면 그 지시를 따른다. 확인 대기 중에는 기존 번역을 유지하고 동기화 예정임을 보고한다.
- 언어가 지정되지 않으면 영어와 일본어를 모두 처리한다. en/ja 직접 편집 요청은 해당 범위에서 수행한다.
- 사용자 미커밋 번역을 보존하고 필요한 변경만 반영한다. 번역 과정에서 새로운 주장·수치·사례·출처를 추가하지 않는다.

## 번역 절차

1. 원문 전체와 기존 번역을 읽고 [공통 번역 규칙](references/translation-rules.md)을 적용한다. 제목·설명·TL;DR·표·이미지 내부 문구·다이어그램·각주까지 의미와 구조를 보존한다. 일본어는 です・ます調, 브랜드는 ROBOCO 라틴 표기를 유지한다.
2. 기존 번역의 부분 수정은 변경된 부분 위주로 동기화한다. 원문과 번역에 서로 다른 사실 판단을 넣지 말고, 원문 오류가 의심되면 보고한다.
3. [이미지·다이어그램 번역 규칙](references/visual-localization.md)을 읽고 본문 이미지, shortcode, frontmatter의 공유 이미지, 인라인 SVG·Mermaid를 조사한다. 설명에 필요한 문구가 대상 언어와 다르면 언어별 자산을 생성하고 해당 번역본의 경로를 교체한다. 사진·로고·텍스트 없는 삽화는 공유한다. 내부 링크는 실제 대응 파일과 발행 상태를 확인한다. 없는 번역 경로를 만들거나 초안 링크를 해결하려고 임의로 발행하지 않는다.
4. 1~2개 파일은 현재 세션에서 번역한다. 3개 이상이면 파일 3개씩, 영어·일본어를 함께 처리하는 배치로 위임할 수 있다. Claude Code에서는 기존 선호인 Opus를 사용한다. Codex에서는 `collaboration.spawn_agent`의 현재 모델 상속을 사용하고 Claude 모델명을 지정하지 않는다. 위임 도구가 없으면 같은 배치를 순차 처리한다. 각 에이전트에 규칙 파일과 대상 파일을 전달하고 커밋·Hugo 실행은 맡기지 않는다.
5. 공개 콘텐츠 변경은 루트 `AGENTS.md`의 독립 마케팅 리뷰를 수행한다. 질문·파일 편집·리뷰 도구도 같은 문서의 환경별 매핑을 따른다.

## 검증과 전달

- 세 언어를 대조해 문단·목록·헤딩·표·코드·각주 누락, 수치 변경, 일본어 문체 혼용을 확인한다. 언어와 무관한 frontmatter와 각주 번호를 보존한다. `images`는 언어별 이미지가 있는 경우 해당 경로로 갱신한다. 정적 페이지의 번역본에서는 `url`을 제거하고 기존 `layout`을 유지한다.
- 대상 파일에 `rg -n '[가-힣]' content/en/<대상>.md content/ja/<대상>.md`와 `rg -n 'ロボコ' content/ja/<대상>.md`를 실행한다. 한국어 잔존은 규칙 파일의 예외에 해당하는지 직접 판별한다. 검색 결과가 없을 때의 종료 코드 1은 정상이다.
- 일반 Hugo 빌드를 임시 출력 경로로 실행한다. 원문이 초안이면 `-D` 빌드도 실행한다. 생성된 페이지의 언어 전환·내부 링크·섹션 앵커·공용 이미지를 확인한다.
- 번역된 모든 이미지의 내부 문구·수치·범례·축·화살표·출처와 alt/캡션을 대조하고 실제 렌더링에서 잘림·겹침·작은 글자를 확인한다. 본문 빌드 성공만으로 이미지 번역 완료를 판단하지 않는다.
- 생성·수정 파일, 언어별 이미지, 공용으로 유지한 이미지의 근거, 발행 상태, 검증 결과, 남은 초안 링크나 원문 문제를 짧게 보고한다. 빌드 성공만으로 번역 품질을 보장하지 않는다.
- 커밋·푸시는 현재 요청에 권한이 포함된 경우에만 한다. 커밋할 때 번역 변경은 논리적으로 분리하고 저장소의 Git 규칙을 따른다.
