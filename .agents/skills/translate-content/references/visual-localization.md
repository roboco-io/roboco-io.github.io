# 이미지·다이어그램 현지화

번역 대상 글의 마크다운 이미지, figure shortcode, HTML img/picture/srcset, frontmatter images, 인라인 SVG·Mermaid를 확인한다. 기존 번역본의 일괄 조사를 요청받으면 원본 파일 목록뿐 아니라 Hugo 생성 HTML의 실제 이미지 참조도 조사한다. 외부 이미지·CSS 배경·동적 생성 이미지가 있으면 별도로 확인한다.

## 번역 필요성 판단

- 사진, 저자 아바타, 로고, 텍스트 없는 삽화는 공용으로 유지한다. 제품명·코드 식별자만 있는 그림도 불필요하게 복제하지 않는다.
- 설명 문장, 제목, 축, 범례, 노드, 조건, 주의사항에 독자가 읽어야 할 다른 언어가 있으면 현지화한다. 영어 원본도 일본어 독자에게 설명이 필요한 인포그래픽이면 일본어판을 만든다.
- SVG는 text/title/desc와 foreignObject 등을 읽고 렌더링한다. PNG/JPEG/스크린샷과 글자가 path로 변환된 SVG는 시각 확인 또는 OCR로 문구를 파악한다. 확장자나 alt만 보고 번역 불필요로 판정하지 않는다.
- 인용 스크린샷은 원문 증거를 조작하지 않는다. 필요하면 번역한 설명도·표를 별도 자산으로 만들고 번역본임을 표시하며 원본 링크와 출처를 보존한다. 수치와 시점은 원문을 유지하고 최신 데이터처럼 제시하지 않는다.

## 자산 생성과 경로

- 원본 한국어 자산을 덮어쓰지 않는다. 예: `/posts/images/topic/en/diagram.svg`, `/posts/images/topic/ja/diagram.svg`. 단일 파일은 `/posts/images/en/name.svg`도 가능하다. 실제 파일은 대응하는 `static/` 아래에 둔다.
- 수정 가능한 SVG·Mermaid·차트 소스는 직접 현지화한다. 비트맵을 편집해야 하면 사용 가능한 이미지 편집 도구/스킬 지침을 따른다. 단순 데이터 도표는 원문을 충실히 옮긴 SVG로 재작성할 수 있다.
- 의미·숫자·단위·화살표·분기·색상 의미·출처를 보존한다. 원문에서 조건부인 기능을 번역에서 기본 기능이나 보장으로 강화하지 않는다.
- 본문 이미지뿐 아니라 alt, figure title/캡션, SVG title/desc, 공유용 images도 현지화한다. 본문의 외부 출처 URL과 원본 이미지 링크는 유지한다.
- 새 번역 문자열이 길면 줄바꿈·도형 크기·배치를 조정한다. 글자만 과도하게 줄여 맞추지 않는다.

## 검증과 유지

- 대상 언어가 아닌 잔존 문구를 검색하고 고유명사 등 정당한 예외를 확인한다. 인라인 Mermaid도 같은 기준으로 검사한다.
- 생성한 이미지 전부를 렌더링해 텍스트 잘림·겹침·한글/일본어 폰트·범례·화살표를 확인한다. 긴 문구는 실제 표시 크기에서도 읽을 수 있어야 한다.
- Hugo 빌드 후 각 번역 페이지가 해당 언어 자산을 가리키는지, 경로와 이미지가 실제로 존재하는지 확인한다. 배포 시 실제 URL도 확인한다.
- 원본 그림이 바뀌면 해당 언어별 그림도 동기화한다. 검토 기록에는 원본, 사용 페이지, 언어, 번역 필요 여부, 생성 경로, 확인하지 못한 범위를 남긴다.
