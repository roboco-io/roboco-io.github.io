# 콘텐츠 번역 공통 규칙 (EN/JA)

소스: `content/ko/...` → 출력: `content/en/...`, `content/ja/...` (동일 상대 경로·파일명)

## Frontmatter
- `title` 번역 (있다면 `summary`/`description`도). `date`, `draft`, `toc`, `images`, `tags`, `categories`는 값 그대로 유지 (tags/categories 값 번역 금지)
- 정적 페이지의 `url:` 필드는 en/ja 버전에서 제거 (언어 프리픽스 기본 경로 사용). `layout`은 그대로 유지
- 새 필드 발명 금지

## 본문
- 완전하고 충실한 번역: 문단·목록·표·각주 누락 금지, 내용 창작 금지, 수치·통계는 원문과 1:1 대조
- 마크다운 구조 1:1 보존: 헤딩 레벨, 볼드, 리스트, 표(정렬 포함), 코드 블록(코드·명령은 번역 금지, 한국어 주석만 번역), 블록쿼트, 각주
- 유명 인용문이 한국어로 번역돼 있으면: EN은 알려진 원문을 정확히 복원(변형 금지), JA는 의미를 살려 자연스럽게 번역

## 링크·이미지
- 이미지 src(`/posts/images/...`)는 절대 변경 금지 (ko 루트에서 서빙됨)
- 내부 페이지 링크는 언어 프리픽스 부여: `/posts/<slug>/` → `/en/posts/<slug>/` 또는 `/ja/posts/<slug>/`; `/about/`,`/solutions/`,`/products/`,`/contact/` 도 동일
- 한국어 섹션 앵커 딥링크(`/posts/<slug>/#한글-앵커`)는 번역 페이지에 해당 앵커가 없으므로 포스트 루트 링크로 단순화
- 외부 링크는 그대로

## Hugo shortcode
- `{{< figure src="..." title="..." >}}`: src 유지, title/캡션만 번역
- 저자 캡션 고정 번역: EN `"Dohyun Jung - Principal Consultant, ROBOCO"`, JA `"チョン・ドヒョン - ROBOCO首席コンサルタント"` (主席 아님)

## 영어 (EN)
- 네이티브 전문 테크 블로그 문체, 기계번역 투 금지. 관사·수일치 정확히 (예: "an 8-task benchmark")
- 바이브 코딩 → vibe coding. 제목은 자연스러운 영어 제목 어순으로
- 원문자(①②③)는 (1)(2)(3)으로 현지화
- 숫자 범위는 en dash: `5–18×`, `$18–25`

## 일본어 (JA)
- **です・ます調 필수** (だ・である調 금지 — 단, 인용된 문서 발췌 내부는 예외 가능)
- 전각 구두점·괄호（）・？ 사용, 일본어 조판 관례 준수
- 숫자 범위·배수는 일본어 관례: `5〜18倍`, `$18〜25`
- 바이브 코딩 → バイブコーディング. 외래 개념어는 자연스러운 기존 역어 우선 (progressive disclosure → 段階的開示, caveat → 注意点/留意点 — 어색한 가타카나 조어 금지). 신조어 고유명사는 첫 등장 시 카타카나+원어 병기 예: ラルフループ（Ralph loop）

## 고유명사·브랜드
- **ROBOCO는 어느 언어에서든 라틴 문자 유지** (ロボコ 금지). VAF, VDLC, Persona Insight 등 서비스명도 영문 유지
- Claude Code, Karpathy, MCP, OpenClaw, GraphRAG 등 제품/인명/기술명은 영문 유지
- ko 원문에 이미 영문 표기가 있으면 그 표기 우선
- EN에서 "한국 고객 환경" 등 한국 한정 표현은 글로벌 독자 대상으로 일반화 가능(JA는 韓国 유지) — 확정된 편집 방침

## 정당한 한국어 잔존 (잔존 검사 예외)
- 한국어 자체를 다루는 예시 텍스트 (예: 토큰화 예시 "안녕하세요")
- 한국어 자료를 가리키는 각주·참고문헌의 원제
- tags/categories 값
